# くらしノート｜藤沢・寒川

暮らしの情報を、毎朝まとめて。

藤沢市・寒川町を中心に、暮らしに関わる情報をわかりやすくまとめている、個人運営の情報サイトです。

サイト：https://yokoyama-yumihiko.github.io/kurashi-note/

## 載せていること

- **今朝のニュース**：暮らしに関わるニュースを毎朝短くまとめ、元の記事へのリンクを付けています
- **くらしの制度**：給付・補助・申し込みなどのうち、公式の案内を確認したものを期限の近い順に
- **まちのイベント・グルメ**：お祭りや催し、新しいお店の話題（広告記事は載せていません）

## しくみ

- 静的サイト（GitHub Pages）。ページは `tools/build.py`（Python 標準ライブラリのみ）が `data/` から作ります
- ニュース候補は `tools/collect_news.py` が公式サイトや地域紙の一覧から集め（AIは使いません）、
  AI（Claude）が選んで短くまとめ、運営者が確認してから公開します。手順は `docs/morning-brief.md`
- 要約は自分の言葉で書き、記事の本文や写真は転載しません

## ご利用にあたって

市・県・国などの公式の発信ではありません。申請の期限や金額など大事なことは、必ずリンク先の公式の発表で確かめてください。

運営：横山弓彦（藤沢市在住）
