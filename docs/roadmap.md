# くらしノート Development Roadmap

## 1. Goal

くらしノートを、
公共政策の調査・分析・可視化・情報発信を行う
オープンな政策プラットフォームへ発展させます。

開発は段階的に進め、
各フェーズで実際に使える成果物を完成させます。

## 2. Phase 1 — Foundation

目的：
開発基盤を安定させる。

- GitHubリポジトリ整備
- GitHub Desktop運用
- VS Code開発環境
- Git基本運用
- README整備
- docs整備
- 開発ルール策定
- デザイン原則策定

Status: In Progress

## 3. Phase 2 — くらしノート Web

目的：
くらしノート Webサイトを政策情報プラットフォームへ発展させる。

- トップページ改善
- 政策記事
- データ表示
- 検索
- レスポンシブ対応
- アクセシビリティ改善
- GitHub Pages運用改善

## 4. Phase 3 — Data Platform

目的：
政策データを蓄積・整理・再利用できるようにする。

対象：

- 国
- 神奈川県
- 藤沢市・湘南地域
- 自治体オープンデータ
- 議会資料
- 統計
- 予算・決算
- 政策資料

将来的にはAPI・データベース導入も検討します。

## 5. Phase 4 — Visualization

政策を視覚的に理解できる機能を追加します。

- グラフ
- 地図
- タイムライン
- 政策比較
- 地域比較
- ダッシュボード

## 6. Phase 5 — くらしノート App

Flutterを利用して、
iOS / Android対応アプリを開発します。

候補機能：

- 地域情報
- 子育て・教育情報
- 防災情報
- 公共交通
- 地図
- 政策データ
- 市民向け情報検索

## 7. Phase 6 — AI Research

AIを活用した政策調査支援機能を検討します。

- 資料検索
- 要約
- データ分析
- 出典管理
- 政策比較
- 議会資料分析

AIによる回答は、
根拠・出典を確認できる設計を重視します。

## 8. Development Principle

くらしノートは最初から巨大なシステムを作りません。

Small
→ Test
→ Learn
→ Improve
→ Scale

を繰り返しながら成長させます。
