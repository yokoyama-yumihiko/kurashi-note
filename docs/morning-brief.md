# 朝のニュース 下書きの作り方（AI向け手順）

毎朝6時に、この手順で「今朝のニュース」の下書きを作る。公開は本人が確認してから。
利用枠（トークン）を使いすぎないため、ニュース探しはプログラムに任せ、AIは選ぶ・短く書くだけにする。

## 手順

1. `python3 tools/collect_news.py` を実行し、`data/_candidates/YYYY-MM-DD.json` を作る（AIは使わない）
2. 候補を読み、**8〜10本** を選ぶ
   - 優先：藤沢市 → 寒川町 → 神奈川県。暮らしに直接関わるもの（申し込み・期限・料金・防災・健康・子育て・交通・事故や個人情報の漏えいなど）を先に
   - 選ばない：イベント告知だけのもの・部署名だけの見出し・職員募集・議員や政党の活動報告・同じ話題の重複（第2報があれば新しい方だけ）
   - 茅ヶ崎市の話題は載せない
3. 全国のニュースは、暮らしに関わる大きな話題があれば **1〜2本だけ** 足す（WebSearch は1〜2回まで）。中身を確かめられなければ入れない
4. `data/news/YYYY-MM-DD.json` を `docs/news-data.md` の形で書く
   - `title`：元の見出しのまま
   - `summary`：見出しと説明文（excerpt）に書いてあることだけを、自分の言葉で2文以内。**書いていない数字・日付・名前を足さない**。説明文がなく中身がわからないときだけ、元のページを1回読む（1日5本まで）。それでもわからなければ選ばない
   - `impact`：暮らしにどう関わるかを1文。誰に関係するか・何をすればよいかがわかるように。推測になる場合は「〜の可能性があります」と書く
   - 記事の文章をそのまま写さない（著作権）。評価・意見・政治的な主張を書かない
   - `keywords`：今日の話題を表す言葉を3つ
   - `today_in_history`：出典で確かめられる記念日だけ。確かめられなければ項目ごと入れない
5. `python3 tools/build.py --check` で確認し、エラーがあれば直す
6. `python3 tools/build.py` でページを作る
7. 本人に見せて、OKが出たら commit・push する（自動公開に切り替えるかは本人が決める）

## 文体

- 結論を先に。専門用語は使わないか、括弧で短く説明する
- 学生・子育て世代・高齢者の誰が読んでもわかる言葉で
- 1本は読んで30秒以内に収める
