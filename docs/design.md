# くらしノート Design System

## 1. Design Philosophy

くらしノートのデザインは、

「公共政策を、難しく見せない。」

ことを基本思想とします。

行政資料や研究資料の信頼感を保ちながら、
市民・学生・専門家の誰でも読みやすい
シンプルなデザインを目指します。

## 2. Design Principles

1. Clarity
   - 情報を分かりやすく整理する

2. Trust
   - 公共政策プラットフォームとしての信頼感を重視する

3. Accessibility
   - 年齢や利用環境にかかわらず読みやすくする

4. Mobile First
   - スマートフォンでも快適に利用できる設計にする

5. Data Visualization
   - 数字や政策を図・グラフ・地図で理解できるようにする

## 3. Visual Style

基本デザイン：

- White
- Navy
- Green
- 余白を広く使う
- 装飾を増やしすぎない
- 写真・地図・図表を効果的に使う
- 情報の優先順位を明確にする

## 4. Typography

文章は、

Headline
→ Summary
→ Evidence
→ Detail

という情報階層を意識します。

長文をそのまま掲載せず、
見出し・要約・図表を使って整理します。

## 5. Policy Content Design

政策コンテンツでは可能な限り、

課題
→ データ
→ 暮らしへの影響
→ 政策
→ 根拠・出典

という流れで情報を提示します。

## 6. Future Design

将来的には、

- Policy Dashboard
- Interactive Map
- Data Visualization
- Policy Comparison
- Timeline
- Search
- AI Research Interface

などを統一されたデザインシステムで提供します。
